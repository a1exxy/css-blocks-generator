# CSS Blocks Generator

Интерактивный инструмент, в котором пользователь настраивает раскладку Flexbox или Grid, видит её вживую и получает готовые CSS и HTML.

## Language

**Генератор**:
Вкладка инструмента для одной технологии раскладки (Flexbox или Grid): настройки, превью и вывод.
_Avoid_: конструктор, редактор, блок

**Контейнер**:
Родительский блок раскладки, к которому применяются свойства flex- или grid-контейнера.
_Avoid_: обёртка, wrapper, родитель

**Элемент**:
Дочерний блок внутри контейнера.
_Avoid_: ячейка, item, ребёнок

**Общие настройки элементов**:
Значения свойств, применяемые ко всем элементам контейнера сразу.
_Avoid_: настройки всех блоков

**Настройка элемента**:
Переопределение значений для одного выбранного элемента; имеет приоритет над общими настройками элементов.
_Avoid_: индивидуальные стили, override

**Превью**:
Живая раскладка, отражающая текущие настройки.
_Avoid_: предпросмотр, песочница

**Вывод**:
Сгенерированные по настройкам CSS и HTML, которые можно скопировать.
_Avoid_: результат, экспорт, код
