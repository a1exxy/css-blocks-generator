# 05: «Копировать» и «Сбросить» для Flexbox

**What to build:** у Flexbox-генератора есть кнопки «Копировать» для CSS и HTML (с подтверждением) и «Сбросить», возвращающая генератор к значениям по умолчанию. Общий код кнопок пригоден для повторного использования в Grid.

**Blocked by:** 02

**Status:** ready-for-agent

- [x] «Копировать» кладёт в буфер текст CSS (или HTML) без разметки подсветки и показывает краткое подтверждение
- [x] «Сбросить» возвращает все настройки Flexbox-генератора к значениям по умолчанию и снимает выбор элемента
- [x] Сброс не затрагивает состояние вкладки Grid
- [x] Логика копирования и сброса вынесена в общий код, а не привязана к Flexbox
- [x] Сквозные тесты Playwright
