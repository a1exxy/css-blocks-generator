# 04: Flexbox: настройка элемента по клику

**What to build:** пользователь кликает элемент в превью, видит, что он выбран, и настраивает его отдельно: `width`, `height`, `margin`, `padding`, `order`, `align-self`, `flex-grow`, `flex-shrink`, `flex-basis`. Настройка элемента приоритетнее общих настроек элементов.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Клик по элементу выбирает его и показывает панель настройки элемента; выбранный элемент визуально отличается
- [ ] Повторный клик по выбранному элементу снимает выбор
- [ ] Поля настройки элемента применяются только к выбранному элементу в превью
- [ ] CSS-вывод содержит отдельное правило для каждого элемента только с непустыми переопределениями
- [ ] Изменение общих настроек не перезаписывает переопределённые значения элемента
- [ ] Уменьшение количества элементов удаляет настройки исчезнувших элементов из вывода
- [ ] Сквозные тесты Playwright
