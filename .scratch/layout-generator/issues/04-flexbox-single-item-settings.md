# 04: Flexbox: настройка элемента по клику

**What to build:** пользователь кликает элемент в превью, видит, что он выбран, и настраивает его отдельно: `width`, `height`, `margin`, `padding`, `order`, `align-self`, `flex-grow`, `flex-shrink`, `flex-basis`. Настройка элемента приоритетнее общих настроек элементов.

**Blocked by:** 03

**Status:** done

- [x] Клик по элементу выбирает его и показывает панель настройки элемента; выбранный элемент визуально отличается
- [x] Повторный клик по выбранному элементу снимает выбор
- [x] Поля настройки элемента применяются только к выбранному элементу в превью
- [x] CSS-вывод содержит отдельное правило для каждого элемента только с непустыми переопределениями
- [x] Изменение общих настроек не перезаписывает переопределённые значения элемента
- [x] Уменьшение количества элементов удаляет настройки исчезнувших элементов из вывода
- [x] Сквозные тесты Playwright
