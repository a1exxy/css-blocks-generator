# 09: Автономность страницы

**What to build:** автоматическая гарантия, что страница остаётся автономной: работает офлайн по `file://`, не обращается к внешним ресурсам, а порядок подключения файлов допускает склейку в один HTML.

**Blocked by:** 08

**Status:** ready-for-agent

- [x] Тест Playwright падает при любом сетевом запросе (кроме `file://`) при открытии страницы и работе во всех вкладках
- [x] Страница не использует ES-модули, CDN, внешние шрифты и `fetch`
- [x] Проверено, что содержимое всех подключённых файлов, встроенное в один HTML в порядке подключения, даёт ту же работающую страницу (скрипт склейки не входит, проверка разовая или тестовая)
