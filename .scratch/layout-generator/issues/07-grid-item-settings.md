# 07: Grid: элементы и настройка элемента

**What to build:** в Grid-генераторе работают общие настройки элементов и настройка элемента по клику, включая размещение по дорожкам (`grid-column/row-start/end`).

**Blocked by:** 04, 06

**Status:** ready-for-agent

- [x] Общие `width`, `height`, `margin`, `padding` применяются ко всем элементам и попадают в вывод
- [x] Клик по элементу выбирает его; повторный клик снимает выбор
- [x] Настройка элемента: `width`, `height`, `margin`, `padding`, `order`, `align-self`, `justify-self`, `grid-column-start/end`, `grid-row-start/end`
- [x] Настройка элемента приоритетнее общих настроек, изменение общих настроек её не перезаписывает
- [x] Элемент можно растянуть на несколько дорожек через start/end; превью и вывод согласованы
- [x] Уменьшение количества элементов удаляет их настройки из вывода
- [x] Сквозные тесты Playwright
