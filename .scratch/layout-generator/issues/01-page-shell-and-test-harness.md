# 01: Каркас страницы и тестовая обвязка

**What to build:** `index.html` открывается двойным кликом (`file://`) и показывает две вкладки-генератора: Flexbox и Grid. Переключение вкладок работает, состояние каждого генератора хранится в памяти и сохраняется при переключении. Базовый собственный стиль, интерфейс на русском. Playwright настроен только для тестов (страница от него не зависит) и есть один сквозной тест.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Страница открывается по `file://` без сервера, сборки и внешних ресурсов
- [ ] Вкладки Flexbox и Grid переключаются, активная вкладка визуально выделена
- [ ] Скрипты подключены обычными `<script>` (без модулей); общий код и код каждого генератора разделены
- [ ] Playwright и `package.json` используются только для тестов
- [ ] Сквозной тест по `file://` проверяет открытие страницы и переключение вкладок
