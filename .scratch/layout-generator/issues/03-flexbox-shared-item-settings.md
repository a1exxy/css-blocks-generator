# 03: Flexbox: общие настройки элементов

**What to build:** пользователь задаёт `width`, `height`, `margin`, `padding` сразу для всех элементов Flexbox-генератора; изменения видны в превью и в CSS-выводе.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Поля общих `width`, `height`, `margin`, `padding` применяются ко всем элементам в превью
- [ ] CSS-вывод содержит правило для элементов только с не-дефолтными значениями
- [ ] Вывод соответствует вычисленным стилям элементов в превью
- [ ] Сквозные тесты Playwright
