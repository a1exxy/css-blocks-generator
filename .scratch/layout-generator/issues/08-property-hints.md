# 08: Подсказки на русском для всех свойств

**What to build:** у каждого свойства обоих генераторов есть подсказка `?` с кратким русским описанием значений (написана заново, не скопирована с basicweb.ru).

**Blocked by:** 04, 07

**Status:** ready-for-agent

- [ ] Подсказка есть у каждого поля контейнера, общих настроек элементов и настройки элемента в обоих генераторах
- [ ] Подсказка открывается по действию пользователя и закрывается, не мешая работе с полями
- [ ] Для перечислимых свойств подсказка описывает значения
- [ ] Тест Playwright: у каждого поля есть подсказка с непустым текстом
