# 02: Flexbox: контейнер, превью и вывод

**What to build:** во вкладке Flexbox пользователь меняет настройки контейнера и количество элементов, сразу видит превью и получает CSS- и HTML-вывод с подсветкой. В CSS попадают только значения, отличные от значений по умолчанию.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Поля контейнера: `height`, `display`, `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, `align-content` со всеми значениями из спека
- [ ] Поле количества элементов; превью и HTML-вывод содержат нужное число элементов
- [ ] Превью обновляется сразу при изменении поля
- [ ] CSS-вывод содержит `box-sizing: border-box` и только не-дефолтные значения; соответствует вычисленным стилям превью
- [ ] Вывод показан с подсветкой синтаксиса
- [ ] Некорректное значение в поле не вызывает исключения и не ломает страницу
- [ ] Сквозные тесты Playwright на перечисленное поведение
